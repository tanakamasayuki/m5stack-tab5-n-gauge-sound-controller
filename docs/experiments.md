# 実験計画

要件のうち「実現できるかは実験で判断」とした項目（F-05、F-06 など）について、実験の結果をもとに採否を決める。

## E1：入力電流の記録

- **目的：** パワーパック入力電流の性質をつかむ。
- **構成：** DCジャック中継 → U200 → Tab5。Tab5 で記録し、CSV で取り出す。
- **条件：**
  - 線路に車両がいない状態での待機電流
  - 車両を乗せた状態で、ツマミ0
  - ツマミを少しずつ上げたとき（数段階）
  - ゆっくり発進したとき、急に発進したとき
  - ゆっくり減速したとき、急に停止したとき
  - 方向の切り替え
  - カーブや勾配を通過するとき（あれば）
- **見るポイント：**
  - 待機電流と、走行中の電流の差（S/N）
  - ノイズ、PWM による脈動、集電不良による瞬断
  - U200（10A版）の分解能で足りるか

### E1 の結果（第1回、2026-10-26）

- **条件：** KATO スタンダードSX、車両1編成、ツマミは中くらいで一定。
- **記録：** RAW モード（約 3,500 サンプル/秒、約 6 秒）と、約 1kHz のサンプル（約 15 秒）。
- **バス電圧：** 約 13.6V。
- **入力電流は、PWM に合わせて2つの値を行き来する。**

| 項目 | 値 |
|---|---|
| オフ時（待機電流） | 約 12mA。ツマミを OFF にしたときも約 12mA |
| オン時 | 約 125〜130mA |
| PWM の周波数 | 約 146Hz（周期 約 6.8ms） |
| デューティ比（オンの割合） | 約 0.50 |

**分かったこと**
- 10ms ごとの平均値だけを見ると、PWM の周期とずれるため値がばらつく。
- サンプルを「オン」と「オフ」に分ければ、次の 2 つを**別々に**取れる見込みがある。
  - **デューティ比** ＝ ツマミの位置。速度連動の手がかりになる。
  - **オン時の電流 − 待機電流** ＝ 線路上の負荷。列車がいない、あるいは止まっているのに PWM だけが出ている状態を見分けられる可能性がある。
- 10A 版の分解能（0.5mA）で足りる。

### E1 の結果（第2回、2026-10-26）

- **条件：** 第1回と同じ車両。ツマミを OFF → 25 → 50 → 75 → 100 → 方向切り替え → 逆50 → 負荷なし（車両を外して）50 の順に動かした。
- **記録：** RAW モードで約 75 秒（`logs/e1_raw2.csv`、git の管理対象外）。操作の区切りはチャットで伝えてもらい、データの変化と照らし合わせた。

| 操作 | 平均電流 | デューティ比 | オン時の電流 | PWM |
|---|---|---|---|---|
| OFF | 11.9mA | 0 | − | なし |
| 25 | 約 57mA | 0.51 | 約 100mA | 147Hz |
| 50 | 約 97mA | 0.52 | 約 175mA | 147Hz |
| 75 | 約 150mA | 1.00 | 約 155mA | なし（直流） |
| 100 | 約 235mA | 1.00 | 約 235mA | なし（直流） |
| 方向切り替え中 | 12〜17mA | 0 | − | なし |
| 逆50 | 約 92mA | 0.51 | 約 170mA | 147Hz |
| 負荷なし50 | 約 16mA | 0 | − | パルスが出ない |

**分かったこと**
- **デューティ比は、ツマミの位置を表していない。**
  - 低速側（25、50）は、デューティ比が約 50% で一定で、パルスの高さが変わる。
  - 75 以上はパルスがなくなり、直流になる。
  - 第1回で考えた「デューティ比 ＝ ツマミの位置」という見込みは外れた。
- **平均電流は、ツマミの位置に対して単調に増える**（57 → 97 → 150 → 235mA）。
  - PWM の周期（約 7ms）より長い時間（50〜100ms 程度）で平均すれば、速度連動の手がかりとしてそのまま使えそう。
  - 正方向と逆方向でほぼ同じ値になった。
- **負荷のないときは見分けられる。** パルスが出ず、平均電流は待機電流より数 mA 多いだけ。
- **待機電流は 12〜17mA の範囲で動く。** 方向を切り替えたあとなどに上がる。停止の判定では、この幅を考えに入れる。

**次に確かめること**
- 平均電流が、速度と負荷（車両の種類、室内灯、勾配）からそれぞれどれだけ影響を受けるか（E2）
- 発進・停止・集電不良のときの波形（E3 の入力にする）

## E2：車両による差と、自動正規化の検証

> **当面は実施しない（2026-10-26）。** 車両の種類だけでなく、編成の両数などでも電流は変わる。そのため、車両による差は自動の正規化でざっくり吸収する方針とし、細かくは追わない。

- **目的：** 車両ごとに調整しなくても、状態判定と段階分けができるかを確かめる。
- **条件：**
  - 動力車の種類を変える（2〜3種類）
  - 室内灯あり・なしを比べる
- **見るポイント：**
  - 自動ゼロ点と最大値による正規化で、車両の差を吸収できるか

## E3：状態判定アルゴリズム

- **目的：** 停止・発進・走行中・加速・減速を判定できるかを確かめる（F-05）。
- **方法：** E1 と E2 のデータを PC 上で再生して、判定ロジックを試す。
  - 平滑化
  - ヒステリシス
  - 電流の傾き（増えているか、減っているか）
- **実装：** `libraries/TrainSense`。10ms ごとの平均電流を渡すと、状態と level（0〜1）を返す。実機と PC 上のテストで同じコードを使う。
- **テスト：** `tests/train_state/`。E1 第2回の記録を 10ms ごとの平均値に変換し（`tools/raw_to_windows.py`）、それを入力にする。
- **見るポイント：**
  - 減速を判定するまでの遅れ
  - 集電不良による誤判定
  - 走行中を何段階に分けられるか（F-06）

### E3 の結果（第1版、2026-10-26）

E1 第2回の記録で、実際の変化点（100ms 平均が 30mA をまたいだ時刻）と判定を比べた。

| 実際の変化 | 時刻 | 判定 | 遅れ |
|---|---|---|---|
| 動き出し | 27.68s | 28.0s に発進、28.4s に走行中 | 約 0.3s |
| ツマミを 100 から 50 へ | 52s 付近 | 52.2s に減速、53.3s に走行中へ戻る | − |
| 停止 | 55.01s | 55.2s に減速、55.4s に停止 | 約 0.4s |
| 逆50 で動き出し | 60.51s | 60.7s に発進 | 約 0.2s |
| 負荷なし | 67.03s | 67.3s に停止。以降は停止のまま | 約 0.3s |

- level の平均は、ツマミの位置の順（25 < 50 < 75 < 100）に大きくなった。
- 待機電流は 12mA から始まり、方向切り替えのあとに 14mA 程度まで追従した。
- この記録では、ツマミを素早く動かしている。ゆっくり加減速したときの記録は、まだない。

### E3 の結果（第2版、2026-10-26）

Tab5 上のライブモニタ（`experiments/E3LiveMonitor`）で、ゆっくり加速・減速した記録（`e3_run1`）を取り、判定を見直した。

**第1版の問題**
- 10ms の区切りに PWM のパルスが 1 回入るか 2 回入るかで、平均値が大きくばらつく。画面の描き換えで読み取りが止まると、さらに谷の値を拾いやすくなる。
  - 対策：読み取りを専用タスクに分けた。平滑化を 100ms から 200ms にした。
- ゆっくりツマミを上げると、基準値まで一緒に上がってしまい、発進の判定が約 6 秒遅れた。
  - 対策：基準値は、下へはすぐ追従し、上へは停止中にゆっくり（20 秒）だけ追従する。
- ゆっくり減速すると、減り方が毎秒 −15〜−50mA と緩やかで、減速と判定されなかった。
  - 対策：傾きを mA/s ではなく「level が 1 秒あたりどれだけ変わるか」で判定する。傾きの平滑化も長くした（1 秒）。
- 方向切り替え後や負荷なしのときは、待機電流が 16〜17mA まで上がり、停止のしきい値と重なって停止の判定が揺れた。
  - 対策：しきい値を、動いたとみなす 12mA、止まったとみなす 8mA にした。

**第2版の判定**

| 記録 | 実際の変化 | 判定 |
|---|---|---|
| e1_raw2 | 動き出し 27.68s | 28.0s に発進 |
| e1_raw2 | 100 から 50 へ下げる 52s 付近 | 52.1s に減速 |
| e1_raw2 | 停止 55.01s | 55.8s に停止 |
| e1_raw2 | 逆50 で動き出し 60.51s | 60.7s に発進 |
| e1_raw2 | 負荷なし 67.03s | 67.1s に減速、67.7s に停止 |
| e3_run1 | ゆっくり上げ始め 13s ごろ | 14.2s に発進 |
| e3_run1 | ゆっくり下げ始め 40s | 40.8s に減速、49s（ほぼ一定の低速）で走行中に戻る |
| e3_run1 | 停止 55s ごろ | 56.0s に停止 |

- 停止の判定は、平滑化を長くした分だけ遅くなり、0.7 秒前後になった。
- ゆっくり上げている間に、減速や停止と判定されることはなかった。

### E3 の結果（第3版、2026-10-26）

- **加速**の状態を追加した。走行中に、level の傾きが毎秒 +0.04 を超えたら加速、毎秒 +0.015 を下回ったら走行中に戻る（減速と対称）。
- 発進は「停止から動き出した直後」だけに使う。発進のまま 3 秒たっても増え続けているときは、加速に移る。
- 素早く操作した記録（e1_raw2）では、ツマミを上げた直後（37s、41.4s、46.4s）にそれぞれ短い加速が入る。
- ゆっくり上げた記録（e3_run1、e3_run2）では、上げている間の大半が加速になる。

### E3 の調整（2026-10-26）

- 加速・減速のしきい値を、level の傾きで毎秒 ±0.04 から **±0.08** に上げた。走行中に戻すしきい値も ±0.015 から **±0.03** に上げた。
  - ゆっくりした加減速や、周回ごとの負荷の揺れでは、加速・減速にならない。傾きが大きいときだけ加速・減速になる。
- level の範囲の初期値を 150mA から **176mA** にした。待機電流 12mA のとき、100mA で level 0.5 になる。それより大きな電流が流れれば、範囲は運転中に広がる。
- 定速で周回した記録（e3_steady、約 95mA、±5% の揺れ）を、テストの入力に加えた。
