# 実験計画

要件のうち「実現できるかは実験で判断」とした項目（F-05、F-06 など）について、実験の結果をもとに採否を決める。

## E1：入力電流の記録

- **目的：** パワーパック入力電流の性質をつかむ。
- **構成：** DCジャック中継 → U200 → Tab5。Tab5 で記録し、CSV で取り出す。
- **条件：**
  - 線路に車両がいない状態での待機電流
  - 車両を乗せた状態で、ツマミ0
  - ツマミを少しずつ上げたとき（数段階）
  - ゆっくり発進したとき、急に発進したとき
  - ゆっくり減速したとき、急に停止したとき
  - 方向の切り替え
  - カーブや勾配を通過するとき（あれば）
- **見るポイント：**
  - 待機電流と、走行中の電流の差（S/N）
  - ノイズ、PWM による脈動、集電不良による瞬断
  - U200（10A版）の分解能で足りるか

## E2：車両による差と、自動正規化の検証

- **目的：** 車両ごとに調整しなくても、状態判定と段階分けができるかを確かめる。
- **条件：**
  - 動力車の種類を変える（2〜3種類）
  - 室内灯あり・なしを比べる
- **見るポイント：**
  - 自動ゼロ点と最大値による正規化で、車両の差を吸収できるか

## E3：状態判定アルゴリズム

- **目的：** 停止・発進・走行中・減速を判定できるかを確かめる（F-05）。
- **方法：** E1 と E2 のデータを PC 上で再生して、判定ロジックを試す。
  - 平滑化
  - ヒステリシス
  - 電流の傾き（増えているか、減っているか）
- **見るポイント：**
  - 減速を判定するまでの遅れ
  - 集電不良による誤判定
  - 走行中を何段階に分けられるか（F-06）

## E4：Tab5 の音声性能

- **目的：** サウンド面の実現性を確かめる（F-03、F-06）。
- **見るポイント：**
  - 同時に鳴らせる音の数
  - 音の高さや音量を連続的に変えたときの処理負荷
  - クロスフェードの品質
  - タッチしてから音が出るまでの遅れ
  - 内蔵スピーカーの音質と音量
