# 画面要件

**バージョン：** 0.1（ドラフト）
**関連：** [requirements.md](requirements.md)

## 1. 前提

- **画面：** Tab5（5インチ、1280×720）。
  - 横向きを基本とする。
- **使う場面：** 片手でパワーパックのツマミを回しながら、もう片方の手でちょっと触る。
  - 視線は主に線路にあるので、画面は「ちらっと見て押せる」ことを優先する。
- **雰囲気：** LEGO の列車アプリのように、カジュアルで分かりやすく、楽しい見た目にする。
  - 明るい配色にする。子どもにも分かるよう、ボタンには大きなアイコンを入れる方向とする。
- **デザインの進め方：** `ui/SoundBoxScreen.lgfxsb.json` を LGFXScreenBuilder のオーサリングツールで開いて調整する。PC 上のテスト（`tests/screens/`）で全シーンを PNG に書き出して確認する。
- **作り方：** 画面は [LGFXScreenBuilder](https://github.com/tanakamasayuki/LGFXScreenBuilder) で設計する。
  - プロファイルは Tab5 の1つだけとする。

## 2. 画面一覧

| ID | 画面 | 役割 |
|---|---|---|
| SC-01 | 起動 | microSD の音源パックを読み込む。U200 を検出する |
| SC-02 | 運転 | メイン画面。効果音ボタン、走行状態、車両名を表示する |
| SC-03 | 車両選択 | 音源パックを選ぶ |
| SC-04 | 設定 | 音量、電流モニタ、クレジットなど |
| DL-01 | メッセージ | エラーや確認を、透過シーンのダイアログで表示する |

### 画面遷移

```
SC-01 起動 ──→ SC-02 運転 ⇄ SC-03 車両選択
                   ⇅
               SC-04 設定
```

- 電源を入れたら、前回選んでいた車両で SC-02 運転画面を直接開く。
- SC-03 と SC-04 からは、1タップで SC-02 に戻れる。

## 3. SC-02 運転画面

### 3.1 タッチ領域の大きさ

Tab5 の画面は、実寸で約 110.7mm × 62.3mm です（約 294ppi、1mm ≒ 11.6px）。

| 目安 | 実寸 | px |
|---|---|---|
| 一般的なタッチ UI の最小（Apple 44pt、Google 48dp 相当） | 7〜9mm | 81〜104 |
| 大人が確実に押せる | 10mm | 116 |
| **子どもでも押し間違えにくい（このアプリの基準）** | **20mm 以上** | **231 以上** |
| ボタンとボタンの間隔 | 3mm 以上 | 35 以上 |

- **画面全体でも、20mm 角のボタンは 4×2〜5×2 個程度しか入らない。** そのため、運転画面でタッチできる要素は約 8 個までに絞る。
- 小さくなりがちな操作（音量、設定など）は運転画面に置かず、設定画面に移す。
- 子どもが押すと困る操作（設定画面を開くなど）は、長押しにする。

### 3.3 要素

| ID | 要素 | 内容 | 優先度 |
|---|---|---|---|
| M-01 | 車両名 | 選んでいる音源パックの名前。上の帯に表示する（表示のみ） | Must |
| M-02 | 効果音ボタン | 音源パックで定義したボタンを 3×2 に並べる。ラベルはパックから取る。使わない枠は隠す | Must |
| M-03 | 走行状態表示 | 停止・発進・走行中・減速を、文字と色で表示する | Must |
| M-04 | 電流検出の状態 | U200 が見つかった・見つからない、を表示する | Must |
| M-05 | ぜんぶとめる | 鳴っている音をすべて止める | Must |
| M-06 | 手動の発車・停車 | 電流検出がないときだけ、メーターの位置に出す。走行音を手で開始・停止する（F-11） | Must |
| M-07 | 車両をかえる | SC-03 車両選択画面を開く | Must |
| M-08 | 設定 | 上の帯を長押しすると、SC-04 設定画面を開く。音量は設定画面で調整する | Must |
| M-09 | メーター | 電流の強さ（正規化した値）を、バーやメーター風に表示する（F-07） | Should |

**駅到着（F-08）と環境音（F-09）** は、専用のボタンを置かない。効果音ボタンの「種類」として音源パックで定義し、6 個の枠のどれかに割り当てる。

- 駅到着：複数の音を順番に流す種類のボタン
- 環境音：押すたびにオンとオフが切り替わる、ループ再生の種類のボタン

### 3.4 効果音ボタン

- **ボタンの数：** 1 パックにつき**最大 6 個**（3×2）とする。
  - 子どもでも押し間違えにくい大きさ（20mm 以上）を保つため。
  - KATO サウンドボックスの押しボタンも 6 個なので、それと同じ数になる。
  - ページ送りは付けない。
- **大きさ：** 260×260px（約 22.5mm 角）。ボタンとボタンの間隔は 3mm 以上あける。
- **鳴らすタイミング：** 指が触れた瞬間に鳴らす。離したときではない。
- **押したときの見た目：** 押したことが目で見て分かるようにする。
- **長押しで鳴らし続ける：** パックでボタンごとに「長押しの間だけ鳴らす」を指定できる（たとえば警笛）。（Could）
- **同時押し：** 複数のボタンを同時に押せるようにする。マルチタッチに対応する。（Could）

## 4. SC-03 車両選択画面

- 音源パックを、カード形式で一覧表示する。
  - カードには、パックの名前と種別（電車・蒸気機関車など）を出す。
- 1画面に入りきらないときは、ページ送りかスクロールで見せる。
- 選ぶと、すぐ SC-02 に戻り、音源が切り替わる。
- 選んだパックは保存しておき、次に起動したときにも使う。

## 5. SC-04 設定画面

| 項目 | 内容 | 優先度 |
|---|---|---|
| 音量 | 主音量。走行音と効果音を別々に調整できると、なお良い | Must |
| 電流モニタ | いまの電流値（mA）、判定した状態、正規化した値を表示する。動作確認と、実験中の確認用 | Must |
| 画面の明るさ | バックライトの明るさを調整する | Should |
| パックの再読み込み | microSD を差し替えたあとに、音源パックを読み直す | Should |
| クレジット | 音源パックのライセンスとクレジットを表示する | Should |
| 感度 | 全体共通の感度設定。置くかどうかは、実験 E2・E3 のあとで判断する | 未定 |

## 6. 共通の要件

- **子どもが使うときの押し間違え対策：**
  - 画面の端から 2〜3mm（約 30px）は、タッチ領域を置かない。ベゼルのきわは、押しにくく誤検出も起きやすいため。
  - 手のひらが当たったときに誤動作しないよう、大きな接触や、一度に多数の点が触れた入力は無視する。
  - 取り消しにくい操作（車両切替、設定）は、確認を入れるか長押しにする。
- 運転中に画面が自動で消えないようにする。スリープしない設定を既定値とする。
- 文字は日本語に対応する。
  - パック名やボタン名は microSD から読むので、**どんな文字が来ても表示できる日本語フォント**（JIS 第一・第二水準程度）を組み込む。
  - Tab5 のフラッシュは容量に余裕があるので、フォントを丸ごと入れる前提でよい。
- 画面の描き換えで、音が途切れたり遅れたりしないようにする。描画と音声を、別々のタスクにすることを想定している。

## 7. LGFXScreenBuilder の制約と、その対応

| 制約 | 対応方針 |
|---|---|
| ボタン部品がない（使える部品は Text・Image・Rect・Line・Circle のみ） | ボタンは Rect と Text の組み合わせで作る。タッチの当たり判定は、アプリ側で行う |
| 当たり判定の座標を取る公開 API がない | LGFXScreenBuilder に、汎用機能として追加する予定（下の「LGFXScreenBuilder への追加予定」） |
| 実行中に変えられるのは文字だけ。表示・非表示の上書きは、仕様にはあるがコード生成が未実装。色は変えられない | 表示・非表示の上書きは、LGFXScreenBuilder 側で実装する予定。押したときの見た目は、通常版と押下版の部品を重ねておき、表示を切り替えて表す。走行状態の色分けも、状態ごとに部品を用意して、どれを表示するかで切り替える |
| 部品の数はビルド時に固定される | 効果音ボタンは、上限数（たとえば 9 個）の枠を置いておき、使わない枠は隠す |
| 画像はビルド時に埋め込む | 音源パック側のアイコン画像（microSD 上のもの）は、overlay で直接描く。または、パックのアイコンはやめて文字だけにする |
| 形が変わる描画は overlay で行う | メーターやレベル表示は、overlay で描く |
| ダイアログ | 透過シーン（LGFXVirtualCanvas 1.4.0 以上）で作る |

### LGFXScreenBuilder への追加予定

LGFXScreenBuilder のセッションと相談して、次の方向でまとまった（2026-10-26）。いずれも、このアプリ専用ではなく汎用の機能として追加する。実装するかどうかは、LGFXScreenBuilder 側で判断する。

| 機能 | 内容 | 判断 |
|---|---|---|
| 表示・非表示の上書き | 部品に「コードから参照する」の印を付けると、`xxxVisible` フィールド（`lgfxsb::OptBool`、3状態）が生成される。true を入れると、デザインで非表示にしたプロファイルでも表示される | 採用 |
| 部品ハンドルと当たり判定 | 印を付けた部品について、`Scene::Main::Part` 列挙型を生成する。`screen.hitTest(main, x, y)` は前面優先で判定し、非表示の部品には当たらない。`screen.bounds(part, rect)` は矩形を返す。対象は Rect・Image・Circle | 採用 |
| 色の上書き | テーマ管理と合わせて設計すべき範囲なので、今回は見送り。将来の拡張候補とする | 見送り |
